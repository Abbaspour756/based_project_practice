# Rock Paper Scissors 🎮

A simple **Rock Paper Scissors** game written in Python.

## 📌 About

Rock Paper Scissors is a game where the player competes against the computer.

Each round, both the player and the computer choose one of three options:

* 🪨 Rock
* 📄 Paper
* ✂️ Scissors

The rules are:

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* If both choose the same option, it is a draw.

## 🚀 How to Run

Make sure you have Python installed.

Clone the repository:

```bash
git clone <your-repository-url>
```

Go into the project directory:

```bash
cd rock-paper-scissors
```

Run the game:

```bash
python src/main.py
```

## 🎮 How to Play

1. Start the program.
2. Choose **rock**, **paper**, or **scissors**.
3. The computer randomly chooses one option.
4. The winner is determined according to the game rules.
5. Play again if you want!
