# Rock Paper Scissors

This is a simple Rock Paper Scissors game. It is written in Python and uses the `tkinter` library for the GUI.

## Project Structure
```
src/
    game.py
```

## Requirements

- Python 3.8 or higher
- Tkinter library 

## How to play

1. Clone the repository.
2. Run the `game.py` file.
3. Follow the instructions on the screen.

## Features

- Simple and easy to use.
- Supports multiple players.
- Random computer choice.
