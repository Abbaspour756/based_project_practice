# 🔐 Password Generator

A simple Python password generator that allows users to create different types of passwords:

* 🔑 Random passwords
* 🧠 Memorable passwords
* 🔢 Random PINs
* ✍️ Custom PINs

## ✨ Features

### Random Password

Generates a random password containing:

* Uppercase letters
* Lowercase letters
* Numbers

The password length must be between **8 and 16 characters**.

### Memorable Password

Creates a password using randomly selected words.

The number of words can be between **2 and 5**, and the words are separated by hyphens.

Example:

```text
library-tornado-buckle
```

### PIN Generator

Generates a random numeric PIN between **4 and 8 digits**.
